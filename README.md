# crispy-octo-invention

zhao 的第一个 GitHub 仓库，2026 年 11 月 15 日创建。

## 在线工具箱

本站已开启 GitHub Pages：https://zhaojiasen47-ctrl.github.io/crispy-octo-invention/

- `index.html` — 工具箱首页
- `tools/password.html` — 随机密码生成器
- `tools/qrcode.html` — 二维码生成器
- `tools/convert.html` — 单位换算（长度 / 重量 / 温度）
- `tools/wordcount.html` — 字数统计
- `tools/pomodoro.html` — 番茄钟

所有工具都在浏览器本地运行，不上传数据。
